# Разминка — сайт для школьников (демо)

## Запуск
Открой `index.html` двойным кликом. Сервер не нужен. Для публикации: загрузи папку на GitHub Pages / Netlify.

## Структура
- `index.html` — только каркас
- `css/themes.css` — ВСЕ цвета тем (CSS-переменные)
- `css/app.css` — вёрстка, анимации, prefers-reduced-motion
- `js/data/questions.js` — список предметов
- `js/data/generators.js` — задания: математика и часть английского генерируются (каждый раз новые числа), русский — из списков
- `assets/flame.png` — огонёк
- `js/store.js` — сохранение в браузере
- `js/streak.js` — огоньки: серия, сгорание, восстановление, награды
- `js/app.js` — экраны и логика занятий

## Как добавить задания
В `js/data/generators.js`:
- новый тип математики: добавь функцию в объект `M` и впиши её имя в `MG` для нужных классов;
- русский: допиши строку в списки `LET`, `CON`, `COM`, `STR` и т. д.;
- английский: допиши глаголы в `PS`, `PA`, `PP` или вопрос в `ADV` (первое число — с какого класса).
Новый предмет: добавь в `WU.SUBJECTS` и в `SET` внизу `generators.js`.

## Как добавить тему
1. В `css/themes.css` скопируй любой блок `[data-theme="..."]`, поменяй имя и цвета.
2. В `js/app.js` добавь строку в массив `THEMES`: `['имя','эмодзи','Название']`.

## Важно
- Внешних библиотек и картинок нет — страница лёгкая.
- Пароль в демо не сохраняется; для настоящей регистрации нужен сервер.
- C++ здесь не нужен: он нужен только если появится тяжёлая логика через WebAssembly. Для этого проекта быстрее всего чистые HTML/CSS/JS.
